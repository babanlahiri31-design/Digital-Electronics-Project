# Digital-Electronics-Project

LogicGate Identifier is an AI-powered web application that classifies digital logic gates from natural-language descriptions using a fine-tuned DistilBERT Transformer model. It identifies seven fundamental logic gates (AND, OR, NOT, NAND, NOR, XOR, XNOR) and provides interactive circuit simulation, truth tables, Boolean expressions, classification confidence scores, electronic component information, and Verilog code generation.

Developed as a Digital Electronics (DE) project, it combines Artificial Intelligence, Natural Language Processing (NLP), and Digital Logic Design to make understanding and identifying logic gates more intuitive and interactive.
